# Codex 多场景 Vlog 剪辑导演

一套可安装到 Codex 的视频分析与剪辑技能，当前提供两种场景分析逻辑：**户外徒步**与**家庭娱乐**。两种场景使用各自的素材观察、事件判断和选片规则，再交给同一套分镜、剪辑计划和 FFmpeg 执行流程。

## 能做什么

- 按场景分析素材并生成有原片时间依据的事件时间轴。
- 生成 Markdown/CSV 分镜及 YAML 剪辑计划。
- 用户要求成片时，继续执行裁剪、衔接、构图、声音处理和导出。
- 徒步模式重点检查路线推进、景观变化、转角显景和人物体验。
- 家庭娱乐模式重点检查人物表情、活动动作、互动回应和情绪变化；固定机位也按事件变化检查。

## 安装

将本仓库的 `skills/` 下六个技能目录复制到 Codex skills 目录：

```bash
mkdir -p ~/.codex/skills
cp -R skills/* ~/.codex/skills/
```

复制后重新打开 Codex 或开始新对话，使用 `$vlog-director`。如果你的 Codex 使用自定义 `CODEX_HOME`，请把目录复制到该目录下的 `skills/`。

## 使用

徒步分析与分镜：

> 用 $vlog-director，类型：户外徒步。素材在【路径】。重点保留转角看到山峰的过程，生成约3分钟的分镜和剪辑计划。

家庭视频并完成剪辑：

> 用 $vlog-director，类型：家庭娱乐。素材在【路径】。以小朋友为主，检查有趣互动和情绪变化，生成约90秒的分镜并完成剪辑，保留重要现场声音。

只分析而暂不渲染时，请明确说“只分析并出分镜，暂不渲染”。可以补充目标时长、画幅、主体、必留事件、配乐目录和说明文件路径。

更多示例见[使用说明](使用说明.md)。

## 技能结构

| 技能 | 用途 |
| --- | --- |
| `vlog-director` | 新的统一导演入口，按本次指定场景调度完整流程 |
| `vlog-highlight-analyzer` | 多场景选片、分镜与剪辑计划 |
| `hiking-vlog-director` | 旧徒步入口的兼容层，也接受明确指定的家庭娱乐类型 |
| `hiking-highlight-analyzer` | 旧选片入口的兼容层 |
| `ffmpeg-analyse-video` | 视频元数据、画面与时间轴分析 |
| `ffmpeg-skill` | 共用的 FFmpeg 剪辑执行工具与参考资料 |

建议从 `$vlog-director` 开始。六个目录应一起安装，以保留技能间的相对引用。
