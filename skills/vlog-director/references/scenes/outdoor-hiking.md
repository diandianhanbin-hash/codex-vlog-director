# 户外徒步场景：outdoor-hiking

## 分析逻辑：路线、空间与体验

以旅程推进为主线，同时观察景观变化与人的真实经历。重点找出发/路牌、路线阶段切换、林间转开阔地、转角后显露山峰、天空和天气变化、独特景色、困难路段、休息补给、同伴互动、到达目标、下山或离开。天空本身并非必留；变化、构图或故事作用要有依据。

1. 探测全部文件，按可验证的拍摄顺序建立源片清单。先以全画幅概览观察环境，短片可每2–4秒取样，较长行进素材可从每8–15秒开始，并结合场景变化补点；这是起始策略，不是所有片长的固定限制。
2. 保持原片从开头到结尾的覆盖，记录实际间隔与未检查范围。镜头急转、空间打开、天气变化、路标和人声提示附近增加取样；不要只保留算法检测出的画面切换点。
3. 对重要 reveal 检查显露之前、转角/运镜过程及显露之后，通常先补查前后10–20秒，再以约0.5–1秒间隔确定可用窗口。避免只留最后一张山峰画面，丢失“发现”的体验；也避免保留冗长无变化的接近过程。
4. 对喘气、对话、感叹、脚步、风、溪水等收集可获取的原声信息；需要理解讲话时使用本地转写并核实关键语义。风噪/音量峰值只作为定位线索，不自动等同于困难或惊喜。
5. 检查步行晃动、地平线、曝光突变、逆光、遮挡、运镜起止。技术质量一般但唯一的到达/人物反应可保留；不要用稳定普通步行替代关键事件。

## 选片逻辑：空间变化有用，重复景色可压缩

优先考虑不可替代的旅程节点、独特景观揭示、明显路线/环境变化、自然人物体验及代表性环境声。七维评价中的 `progression` 指路线与阶段推进；`visual` 看空间、景观、天气、构图和光线，不机械优先于人物事件。

常见角色：`opening`、`orientation`、`transition`、`landscape`、`challenge`、`interaction`、`reflection`、`reveal`、`climax`、`ending`、`ambience`。登顶只有证据存在才使用；路线中途结束不编造到达镜头。

- 同一山峰的相似角度、长时间普通林间步行可归组，选最能体现变化或叙事位置的一段。新天气、视角揭示、人物反应出现时重新判断，不能一律删为重复。
- 优先形成实际素材支持的“建立旅程 → 环境与行进变化 → 体验/困难 → 景观揭示或核心事件 → 自然结束”。不要求每条片子都有困难、登顶或戏剧高潮。
- 普通过渡可短，风景要留看清的时间，reveal 要有显露过程和停留，重要讲话保留语义。参考过渡2–6秒、风景4–10秒、重要揭示6–15秒；依目标时长、动作和声音调整，不固定套数值。

## 分镜与剪辑建议

分镜写出“接近/遮挡 → 转角/抬镜 → 开阔景色”的真实阶段，说明景观与人物镜头的衔接作用。全景优先保留空间，近景用于人物体验或路面细节，必须来自已有画面。

默认自然纪实，环境声与人物声是结构的一部分。BGM 可在普通过程和情绪节点使用；关键自然声或感叹应降低音乐或留原声。用户要求全程音乐时按要求铺设并避让。防抖、调色、转场及输出仍交给共用执行技能。

## 本模式的故事检查项

`opening`、`progression`、`environment_change`、`human_experience`、`reveal`、`core_event`、`ending`。缺少原始记录标记 `not_available`，有记录但剪辑遗漏标记 `missing`，不要为完整性编造。
