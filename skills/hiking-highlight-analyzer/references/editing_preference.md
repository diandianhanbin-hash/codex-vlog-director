# 默认个人剪辑偏好

这是默认偏好配置，用户当前对话中的明确要求优先于本文件。

## 1. 成片目标

- 类型：户外徒步 / 登山 Vlog
- 默认目标时长：6–10 分钟
- 风格：自然、纪实、舒服，有明显旅程感
- 不追求高频卡点，不追求大量视觉特效

## 2. 优先保留

- 出发与结束
- 路线阶段变化
- 第一次出现的重要景观
- 森林转开阔地、山脊、峰顶等明显环境变化
- 困难路段
- 意外事件
- 登顶或到达目标
- 真实的人物反应、喘气、交流、感叹
- 有代表性的自然环境声

## 3. 尽量减少

- 长时间普通步行
- 高度重复的树林
- 高度重复的同一山景
- 没有新增信息的自拍讲话
- 失焦、误拍、遮挡
- 仅为了“凑节奏”而保留的镜头

## 4. 节奏

- 普通过渡镜头：通常 2–8 秒
- 好看的环境镜头：通常 4–12 秒
- 重要景观 reveal：可保留 6–20 秒
- 登顶/核心事件：允许更长
- 讲话片段：优先保留完整语义，不要切碎句子

## 5. 声音

- 优先保留环境声和真实人物声音
- 不建议全程铺 BGM
- 重要景观、风声、溪水、脚步等可以留自然声
- BGM 应服务于结构，不覆盖关键自然声与对白

## 6. 字幕

- 不默认给所有内容加字幕
- 有意义的讲话、路线信息和必要说明可以加字幕
- 不建议大面积“综艺式”字幕

## 7. 叙事倾向

优先形成：

`出发 → 进入路线 → 环境变化 → 过程/困难 → 重要揭示 → 登顶/目标 → 收尾`

如果素材本身不是这个结构，不强行套模板。
