# 徒步视频角色分类表

角色用于描述一个片段在成片中的叙事功能，同一片段允许多个角色。

| role | 含义 | 常见例子 |
|---|---|---|
| opening | 建立旅程起点 | 出门、到达登山口、开始记录 |
| orientation | 帮助理解路线/地点/目标 | 路牌、地图、目的地说明 |
| transition | 连接两个阶段 | 行走、转场、上坡到山脊 |
| landscape | 主要价值是自然或空间景观 | 山谷、森林、溪流、云海 |
| challenge | 体现困难或体力过程 | 陡坡、攀爬、泥路、恶劣天气 |
| interaction | 人物之间或人与环境互动 | 对话、帮助同伴、遇到路人 |
| reflection | 主观感受或阶段性总结 | 对路线、体力、风景的感受 |
| reveal | 重要内容第一次被揭示 | 第一次看到主峰、视野突然打开 |
| climax | 故事高潮 | 登顶、抵达目标、最重要事件 |
| ending | 结束旅程 | 下山完成、返回、收尾总结 |
| ambience | 提供环境感与呼吸感 | 风声、溪水、树林、安静远景 |

## 分类规则

1. 优先判断叙事作用，而不是视觉内容本身。
2. 同一山景如果是第一次出现核心目标，可以同时是 `landscape + reveal`。
3. 登顶镜头通常是 `climax`，若同时包含核心景观，也可以附加 `landscape`。
4. 普通走路不自动等于 `transition`；只有它确实连接阶段或保留旅程感时才使用。
5. 一段讲话只有在体现人物真实感受时才标记 `reflection`。
